# UT1 Backend

Actividad de consultoría backend y demostración práctica con PHP.

## Contenido

- `Informe_Consultoria.md`: informe sobre cliente/servidor, webs estáticas y dinámicas, infraestructura y Laravel 12.
- `fichero_demostracion.php`: prueba de concepto con generación dinámica de contenido mediante PHP.

## Ejecución

1. Clonar el repositorio dentro de `C:\xampp\htdocs`.
2. Iniciar Apache desde XAMPP.
3. Acceder a:

   `http://localhost/ut1-backend/fichero_demostracion.php`

El proyecto utiliza únicamente rutas relativas.
